# antartic-mirror
Edge-native Digital Twin for Maitri &amp; Bharati Antarctic stations. Integrates ML energy, infrastructure, logistics &amp; environment monitoring with an LLM Station Copilot for offline-capable remote management. 0% data loss, >85% compression, &lt;10% MAPE, 8%+ fuel savings. Tech: Python, FastAPI, MQTT, scikit-learn, PuLP, LLM.
